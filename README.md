# 핫딜요약 (hotdeal_summary)

물건 살 때 필요한 정보를 한곳에 모으는 서비스입니다.

| 페이지 | 하는 일 |
|---|---|
| **핫딜** `/` | 뽐뿌(국내·해외·알리뽐뿌·쿠폰·이벤트), 루리웹, 클리앙, 딜바다(국내·해외), 어미새 핫딜을 5분마다 모아서 `[쇼핑몰]·가격·배송비`를 파싱하고, 중복 딜은 묶어서 보여줍니다. 알리만/쿠폰만 필터 지원 |
| **최저가 비교** `/compare` | 네이버쇼핑 API + 다나와 + **알리익스프레스 Affiliate API**를 동시에 조회해 **실구매가**(가격+배송비, 알리는 관부가세 추정치 포함)로 정렬 |
| **AI 최저가** `/research` | 상품 하나를 AI(Claude)가 웹 검색으로 조사해, 우리 수집기에 없는 쇼핑몰·홈쇼핑·브랜드몰·해외직구까지 포함한 **그날의 최저가**를 찾음. 가격은 자동 확인된 것만 최저가로 인정 |
| **가격 추적** `/track` | 폴센트처럼 상품(검색어 최저가 또는 알리 상품 URL — 키 없이도 동작)을 주기적으로 기록 → 목표가 도달 / N% 하락 / 역대 최저가 갱신 시 알림. 핫딜 **키워드 알림**(예: "햇반 72", 최대 가격) |
| **행사** `/events` | 알리 11.11 광군제, 11번가 십일절, 블랙프라이데이 등 일정(D-day) + 관련 핫딜·코드 자동 연결 |
| **쿠폰** `/coupons` | 커뮤니티·유튜버 전용 코드가 올라온 글에서 코드·할인액·최소주문·유효기간·출처를 자동 추출해 정리(클릭 복사) |
| **알림** `/notifications` | 앱 내 알림함 + 텔레그램/디스코드 웹훅 전송 |

### 알리익스프레스를 빠뜨리지 않기
국내 가격비교/가격추적 서비스는 알리를 잘 다루지 않습니다. 여기서는
- 가격비교에 알리를 항상 포함합니다: Affiliate API 키가 있으면 API(`ship_to_country=KR`, `target_currency=KRW`), 없으면 알리 한국 검색 페이지에 내장된 원화 가격 데이터를 사용,
- 면세한도(USD 150, 미국 200) 초과 시 관세+부가세 추정치를 더해 국내가와 같은 기준(실구매가)으로 비교하며,
- 알리 상품 URL을 그대로 추적 등록해 자체 가격 히스토리를 쌓고,
- 알리뽐뿌/클리앙 등에 올라오는 광군제 코드(예: `KBTY04`~`KBTY45`)를 행사와 연결합니다.

### AI 최저가 탐색 (`/research`)
지정한 사이트에 안 보이는 판매처까지 찾기 위해 Claude API의 웹 검색·웹 페치 도구를 씁니다.

1. **조사**: AI가 한국어로 검색하고 상품 페이지를 가져와 후보를 정해진 형식으로 보고합니다. 우리 수집기 결과(다나와·알리·네이버)와 최근 커뮤니티 핫딜을 함께 넘겨 "이보다 싼 곳"을 찾게 합니다.
2. **추출**: 보고서를 구조화된 데이터로 바꾸고, 보고서 원문과 URL·가격이 다른 행은 버립니다.
3. **자동 확인** (AI 말을 그대로 믿지 않음): AI가 가져온 페이지 본문이나 검색 인용문에 **같은 금액이 실제로 있을 때만** "확인됨"입니다. 조사 중 한 번도 나오지 않은 링크(지어낸 링크 의심), 3일 넘은 검색 정보, 목록 페이지, 처음 보는 판매처(사기몰 주의), 일치 상품 중앙값의 절반 미만 가격은 따로 표시합니다.
4. **오늘의 최저가** = 정확히 같은 상품 · 확인됨 · 품절 아님 중 가장 싼 실구매가(배송비, 해외는 관부가세 추정 포함). 더 싸 보이지만 확인 안 된 후보는 경고와 함께 아래에 따로 보여주고 알림에도 쓰지 않습니다.

비용과 안전장치:
- 기본 모델 `claude-opus-5-5`(env `AI_MODEL`), 웹 검색 1,000회당 $10 + 토큰 비용. 1회 조사 비용은 결과 화면에 추정치로 표시됩니다.
- 하루 예산(`AI_DAILY_BUDGET_USD`, 기본 $2)과 1회 상한(`AI_RUN_MAX_USD`)을 넘지 않게 막고, 동시에 하나만 실행하며, 같은 날 같은 상품은 저장된 결과를 다시 보여줍니다(‘다시 조사’로 강제).
- 안전 분류기가 요청을 거절하면 서버가 다른 모델로 다시 실행하도록 `fallbacks: "default"`를 켜 두었습니다.
- 추적 상품에서 **매일 AI 조사**를 켜면 한국 시간 `AI_DAILY_HOUR`(기본 9시) 이후 하루 한 번 조사하고, AI 일별 최저가끼리 비교해 목표가·하락·역대 최저 알림을 보냅니다.
- 돈이 드는 요청은 다른 사이트에서 보낸 POST를 거부합니다. Docker는 기본으로 이 컴퓨터(127.0.0.1)에서만 열립니다. 외부에 공개하려면 로그인/접근 제한을 먼저 두세요.
- 서버 프로세스(워커) 1개 기준입니다. 재시작하면 진행 중이던 조사는 "중단됨"으로 정리됩니다.

```bash
uv run --env-file .env python -m app.cli research "WD BLACK SN850X 1TB"
```

## 실행

```bash
uv sync
```

```bash
uv run python -m app.cli collect
```

```bash
uv run uvicorn app.main:app --reload
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 서버가 떠 있으면 수집(5분)·가격 확인(1시간)이 백그라운드로 돕니다.
API 키는 `.env.example`을 `.env`로 복사해 채운 뒤 `uv run --env-file .env uvicorn app.main:app` 으로 실행합니다.

Docker로 실행(데이터는 볼륨에 보존, `.env`가 있으면 자동 사용):

```bash
docker compose up -d --build
```

기타 명령:

```bash
uv run python -m app.cli compare "에어팟 프로 2"
```

```bash
uv run python -m app.cli check-prices
```

```bash
uv run pytest
```

  services/evidence.py    응답에서 증거 추출 · 금액 자동 확인 · URL 정규화 · 순위
  services/research.py    실행 관리(예산·동시 실행·재사용), 저장, 매일 조사, AI 알림

## 수집 소스 상태 (해외 IP 기준 확인)

| 소스 | 방식 | 상태 |
|---|---|---|
| 뽐뿌 국내/해외/알리뽐뿌/쿠폰/이벤트 | RSS | ✅ (HTML 목록·본문은 해외 IP에서 403 → RSS 요약으로 쿠폰 추출, 국내 서버에선 본문까지 사용) |
| 루리웹 유저 핫딜, 어미새 | RSS | ✅ |
| 클리앙 알뜰구매, 딜바다 국내/해외 | HTML | ✅ |
| 퀘이사존, 아카라이브, 에펨코리아, 쿨엔조이 | - | ⛔ 해외 IP 차단(403/430/timeout) → 기본 비활성. 국내 서버에서 파서 추가 후 `ENABLED_SOURCES`로 활성화 |
| 다나와 검색 | Next.js 내장 JSON | ✅ 키 불필요 |
| 알리익스프레스 검색 | 한국 검색 페이지 내장 JSON | ✅ 키 불필요 (API 키 설정 시 Affiliate API 우선) |
| 네이버쇼핑 / 알리 Affiliate | 공식 API | 🔑 키 필요 |

## 운영 원칙
- 공식 API 우선, 커뮤니티는 RSS/목록 페이지만 낮은 빈도로 조회하고 제목·가격·링크 등 메타데이터만 저장합니다(원문 링크로 이동).
- 각 사이트 robots.txt를 확인해 허용 경로만 사용하고(2026-11 기준), Crawl-delay를 지킵니다: 다나와 10초, 어미새 5초, 그 외 같은 호스트 1초 간격(`app/http.py`).
- 가격·관부가세·쿠폰 정보는 참고용이며 실제 결제 금액과 다를 수 있습니다.
